---

Read the structured data on any page, and see what it is missing.

Parses JSON-LD and Microdata and checks the properties each type requires.

WHAT IT DOES

• JSON-LD, including "@graph" wrappers, arrays and nested entities
• Microdata - "itemscope", "itemtype" and "itemprop", with nested items
• Required and recommended properties for twenty schema.org types, including Product, Offer, Article, LocalBusiness, FAQPage, Recipe, Event, JobPosting and VideoObject
• Blocks that fail to parse, reported with the parser error and an excerpt
• The raw parsed data as a collapsible tree

Copy puts a Markdown report on your clipboard. Export JSON downloads every entity with its findings.

PRIVACY

This extension collects nothing. No account, no sign-up, no analytics, no
telemetry, no servers. It reads the page you explicitly ask it to inspect,
keeps the result in the popup's memory, and forgets it when you close the
popup. Nothing is written to disk unless you click an export button, and
nothing is ever transmitted anywhere.

PERMISSIONS

• activeTab - gives access to the current tab only at the moment you click the
  icon, and only until you navigate away. This is why the extension needs no
  access to your browsing history and no permission to run on every site.
• scripting - required to read the page once you have clicked the icon.

That is the complete list - two permissions. There is no storage, no
background process and no host permissions.

FREE AND OPEN SOURCE

No account, no sign-up, no trial, no paid tier, no upsell. Every feature
works the moment you install it.

The source is open, MIT licensed: github.com/swanca/chrome-inspector-suite

PAGES IT CANNOT READ

Chrome forbids extensions on its own pages - chrome://, the Web Store, and
view-source. The extension says which case you have hit rather than failing
silently. Local files work if you enable "Allow access to file URLs" on its
details page.

## 7. Privacy practices tab

The tab that most often sends a submission back. Every answer here is "no".

**Single purpose**

> Parses the structured data on the page the user is viewing and checks it against the properties each schema.org type requires.

**Permission justifications**

| Permission | Paste this |
|---|---|
| `activeTab` | The extension reads the page the user is on, but only after they click its toolbar icon. activeTab grants that access for that one tab and only until navigation, which avoids requesting host permissions for every site. |
| `scripting` | Used to run a single read-only collector function in the page once the user has clicked the icon. It reads the DOM and returns data to the popup. It never modifies the page. |

**Remote code**

> No. All code is included in the package. Nothing is fetched or evaluated at runtime.
