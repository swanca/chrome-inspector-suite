## 5. Detailed description

---

Every image on the page, with its alt text judged - and a CSV of the lot.

Every image on the page with its alt text judged, and a CSV export.

WHAT IT DOES

• Every "<img>", "<input type="image">", "<area>" and "<svg role="img">" on the page
• A missing "alt" attribute reported as a failure
• An empty "alt=""" recognised as correct - it marks the image decorative
• An empty "alt" inside a link reported as a failure, because the link loses its name
• Weak alt text: over 125 characters, placeholder words, redundant "photo of" prefixes, or text that merely repeats the file name
• Thumbnails, so you can see what each row is talking about

Copy puts the rows on your clipboard as CSV. CSV downloads them as a file.

PRIVACY

This extension collects nothing. No account, no sign-up, no analytics, no
telemetry, no servers. It reads the page you explicitly ask it to inspect,
keeps the result in the popup's memory, and forgets it when you close the
popup. Nothing is written to disk unless you click an export button, and
nothing is ever transmitted anywhere.

PERMISSIONS

• activeTab - gives access to the current tab only at the moment you click the
  icon, and only until you navigate away. This is why the extension needs no
  access to your browsing history and no permission to run on every site.
• scripting - required to read the page once you have clicked the icon.
• storage - keeps a single first-run timestamp on your own device. Nothing else.

That is the complete list. There is no background process and no host
permissions.

EVERYTHING IS INCLUDED

No account, no sign-up, no trial, no paid tier. Every feature works the
moment you install it, including: Export as CSV.

The source is open: github.com/swanca/chrome-inspector-suite

PAGES IT CANNOT READ

Chrome forbids extensions on its own pages - chrome://, the Web Store, and
view-source. The extension says which case you have hit rather than failing
silently. Local files work if you enable "Allow access to file URLs" on its
details page.

At least one is required. 1280x800 or 640x400, PNG or JPEG. These are the

1. A page with problems: thumbnails down the left, FAIL badges on images with no alt.

3. A row showing weak alt text - "alt is just the file name".
4. A well-built page where every image passes.
5. The CSV export open in a spreadsheet, showing the (missing) marker.

Shoot at 1280x800: set Chrome to that window size, open the popup, and
capture the popup together with enough of the page behind it to show the
context. A popup alone on white looks like a screenshot of nothing.

## 7. Privacy practices tab

The tab that most often sends a submission back. Every answer here is "no".

**Single purpose**

> Lists every image on the page the user is viewing and judges its alt text.

**Permission justifications**

| Permission | Paste this |
|---|---|
| `activeTab` | The extension reads the page the user is on, but only after they click its toolbar icon. activeTab grants that access for that one tab and only until navigation, which avoids requesting host permissions for every site. |
| `scripting` | Used to run a single read-only collector function in the page once the user has clicked the icon. It reads the DOM and returns data to the popup. It never modifies the page. |
| `storage` | Stores a licence key on the user's own device so the paid tier does not require an account or a server. Nothing else is stored and nothing is transmitted. |

**Remote code**

> No. All code is included in the package. Nothing is fetched or evaluated at runtime.
